## What went well

1. **RED-before-GREEN on structural tests held every story.** Writing the failing
   `test_persona_contract.py` assertions first — then authoring the markdown to pass
   them — caught contract drift before it shipped. The uniform persona contract paid
   a compounding dividend: 1.4's three new agents passed all existing checks with
   zero test changes.
2. **Live smoke runs found what pytest structurally cannot.** Every story's smoke
   verification surfaced real behavior: 1.4-full's peer reviewers independently
   caught a shared unverified assumption, and the devil's advocate dissolved a false
   binary no seat had escaped. The anti-sycophancy protocol (FR5/FR6) is observable
   in shipped artifacts, not just asserted.
3. **Parallel clean-context review is the highest-leverage step.** The 3-layer fan-out
   (Blind Hunter / Edge Case Hunter / Acceptance Auditor) caught 9 findings on 1.3 and
   7 on 1.4 — including a self-contradicting rule the author had read past twice, and
   the `quick_seats: []` vacuous-subset hole pytest's own subset check would have blessed.
4. **Honest deviation records compounded into fixes.** 1.2 and 1.3 both recorded the
   chairman emitting an extra section / a `high (8 of 10)` confidence. 1.4 *owned* both
   as a render-check pass — and the wobbles did not recur.

## What was hard / what we learned

1. **The chairman output contract was under-specified for quick mode — twice.** 1.2
   built it for full runs; 1.3 added quick mode but left "Blind Spots = what peer review
   surfaced" pointing at a stage quick mode doesn't run; 1.4's review finally caught that
   the exactly-seven-headings check would *pressure fabrication* of a blind spot. **Lesson:
   when a contract is written for the rich path, explicitly re-derive every clause for the
   degraded path in the same story.**
2. **Validation holes hide behind passing tests.** The `quick_seats` vacuous-subset hole
   (1.3) and the unbounded `## Staged` test slice both *passed green* while being wrong.
   **Lesson: a marker test that asserts a substring proves mention, not behavior — assert
   the prohibition, bound the slice, reject vacuous matches.** Now a standing review lens.
3. **Planning artifacts had a real ownership conflict.** `councils/council-default.md` was
   listed in Story 2.3 but blocked 1.4's AC1. Resolved in 1.4 (it authors the roster; 2.3
   shrinks to evaluate/advise + config posture). **Lesson: cross-story file ownership is
   worth a 30-second check at create-story time, not dev time.**
4. **Sub-agents inherit the global CLAUDE.md.** A smoke seat addressed the user by name
   mid-document. Harmless here, but seat prompts now must demand raw-document output.

## Action items (carried into Epic 2)

1. **Re-derive contracts for degraded paths in-story.** When a story adds a mode/branch,
   walk every existing contract clause against the new path before marking the task done.
   _Owner: dev-story step 5._
2. **Marker tests must assert behavior, not mention.** Bound section slices; assert
   prohibitions alongside paths; reject substrings of already-asserted tokens.
   _Owner: standing test-review lens, applied at RED._
3. **Cross-story file-ownership check at create-story.** One grep for the new files'
   paths across epics.md before writing tasks. _Owner: create-story research phase._
4. **Seat prompts demand raw output.** Already in 1.4's render-check note; propagate to
   the real Epic 2 personas. _Owner: Story 2.1/2.2 authoring._
